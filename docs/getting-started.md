# Get started with Brain Scanner

## Explore without an account

[Try the recovery example](https://brainscanner.dev/#recover). Inspect the changed files, failing checks, and earlier decisions. Try a different next step and replay the example. These sample actions stay in your browser.

## Connect your project

1. [Create your account](https://brainscanner.dev/signup), confirm your email if prompted, and open the dashboard. A new account starts with an empty project.
2. Choose **Connect agent**. Follow the dashboard instructions for Claude Code or Codex, and authorize the same Brain Scanner account.
3. Tell your agent which local project to map. Keep the dashboard's project name and ID available so the work stays attached to the right project.
4. Open Project Graph and inspect one useful area, such as a shared helper and its callers. Verify missing or uncertain details against the current source with your agent.

Use the [first project guide](https://brainscanner.dev/guides/first-project-handoff) for the supported setup and mapping steps.

## End with something useful to return to

Ask the agent to record what changed, the checks it actually ran, any remaining blockers, and the next task. On your next visit, review that record before continuing.

- [Review an agent's changes](https://brainscanner.dev/guides/review-agent-changes)
- [Resume with the same or a different agent](https://brainscanner.dev/guides/resume-a-coding-project)
- [Check the impact of a change](https://brainscanner.dev/guides/codebase-impact-analysis)

If the project still says **Agent not connected**, use its connection instructions and complete authorization in your client. Signing in to the website alone does not connect an agent. For help, see [Support](support.md).
